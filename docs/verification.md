## Самостоятельный EXE и размер

Обычная сборка создаёт **один бинарник приложения**. CLI `catalog-check` требует отдельного feature `catalog-tools`. В релиз передаются `SoftDownloader.exe` и необязательный файл контрольной суммы.

Локальная сборка, на которой выполнены GUI-прогоны:

| Артефакт | Значение |
|---|---|
| Версия | 0.5.0, Windows x64 |
| Размер | **7 318 016 байт · 6,98 МиБ** |
| SHA-256 | `ecceeef4e3d535c8a129f847fbd270b52bcb4ba0adb42588602a7d7778c213a8` |
| Профиль | `opt-level=z`, full LTO, статический CRT, `panic=abort` |

Каталог, запасной шрифт, иконка, звуковые клипы и праздничная графика встроены. MP4 загружаются отдельно по запросу. Windows Media Foundation и WinMM используются как системные компоненты; внешних DLL или плеера в поставке нет. Размер и хеш сборки GitHub Actions могут отличаться из-за версии компилятора: для скачанного EXE используйте его `.sha256` из релиза.

`tools/verify_standalone.py` проверяет SHA-256, x64 PE, ресурс иконки и импорт только штатных библиотек Windows. EXE копируется в отдельную папку без других файлов и запускается оттуда. В CI проверяется запуск `--help`; локально дополнительно открыт интерфейс (`--gui`), загружен встроенный каталог и выполнено штатное закрытие с кодом 0. В папке запуска остаётся единственный EXE, данные профиля хранятся отдельно.

### Оформление и звук

- Все темы и пользовательские акценты проверены на контраст основного текста не ниже 4,5:1, включая промежуточные кадры смены светлой/тёмной темы.
- Режим уменьшения движения применяет новую тему сразу. Календарные тесты проверяют октябрь, декабрь/январь и ручной/выключенный режимы.
- Размер слота выбора одинаков для доступного, выбранного, установленного, ручного, недоступного и загружающегося пакета.
- Старые настройки загружаются с новыми значениями по умолчанию; избранное сохраняется, включая ID будущих дополнений.
- Девять звуковых клипов имеют плавные нулевые края, длительность 97–255 ms и пик 2200/32767. Среднеквадратичный уровень подготовленных записей — 151–530/32767.
- Тестируется отдельное ограничение выхода до 2800/32767 даже при полноамплитудном входе и некорректном значении громкости. Нулевая громкость даёт тишину. Автоматические GUI-проверки не проигрывают клипы.

### Нативное видео

- MP4-образец с красным верхом и синим низом проверяет ориентацию, RGB-каналы, конец файла и точную перемотку.
- Тот же тест проходит по каноническому Windows-пути с кириллицей и пробелами. Отдельно проверены padding/отрицательный stride и непрозрачный alpha.
- Настоящие ролики Mixkit проверены CLI: снежный лес — 404×720, 249 кадров; ночные горы — 1280×720, 131 кадр. Перемотка возвращает исходный первый кадр.
- Пропорции портретных и широких видео сохраняются при заполнении фона. Каталог роликов содержит фиксированные размер, SHA-256 и ссылку на источник.

### Экспорт и импорт

- Unicode и атомарная перезапись экспортированного файла.
- Полный круг export → parse: сохранение неизвестного софта, исключение путей/команд, нормализация управляющих символов из реестра.
- Дедупликация ID; уже установленная программа с другой версией не выбирается повторно.
- Неизвестный ID не переназначается по совпавшему имени. Для записей без ID неоднозначное имя отмечается отдельно.
- Неподдерживаемая версия, лишние поля с рецептом установки, некорректный ID, повреждённый JSON и превышение 2 МБ отклоняются.
- План использует текущие версии/рецепты каталога, а не справочную версию из списка.

### Кэш и таймауты

- Повторная загрузка свежего кэша не вызывает сетевой загрузчик; явное обновление вызывает.
- Два профиля имеют независимые кэши. Изменение локального каталога инвалидирует сохранённые данные.
- Повреждённый кэш вызывает обновление с диагностикой. При отказе обновления возраст старого кэша не обнуляется.
- Предыдущий артефакт восстанавливается только для того же источника.
- Тесты с виртуальным временем проверяют реальные незавершающиеся запросы: общий бюджет сохраняет готовые ответы и конкретные ошибки; отдельный источник завершается по собственному таймауту. Интернет в этих тестах не нужен.

### Иконки

- Цвет, прозрачность и полупрозрачность восстанавливаются из отрисовки на двух фонах.
- Проверены чтение системной Windows-иконки, размеры 16–128 и выбор EXE вместо вспомогательных файлов.
- Разбор `DisplayIcon` поддерживает кавычки, пробелы, запятые в пути и суффикс индекса. Извлекается первый ресурс файла.
- Отсутствующая иконка не запрашивается снова каждый кадр; повтор разрешается после обновления инвентаризации.
- Иконка окна и ICO для EXE генерируются из одного рисунка. Ошибка компиляции Windows-ресурса останавливает сборку.

## Живой интерфейс

Приложение запущено с отдельным `--data-dir` и нулевой громкостью. Сканирование обнаружило **195 программ**. Через штатный диалог сохранён JSON со всеми 195 записями; проверены формат и состав полей. Затем импортирован учебный список: два отсутствующих пакета попали в выбор каталога, установленное было отмечено отдельно. Открыт итоговый план установки и закрыто приложение с кодом 0.

Дополнительно выполнено через настоящий интерфейс:

- Список/карточки, сортировка, четыре избранные программы и экспорт всего избранного при поиске, который скрывает все карточки.
- Экспорт выбранного набора, очистка и Ctrl+Z: восстановлены ровно те же два ID.
- Предпросмотр удаления с отменой: очередь не запускалась и журналы удаления не появились.
- Четыре темы, готовый акцент, зимний/хэллоуинский/выключенный режимы; изменение кадров падающего снега.
- Выбор всех звуковых наборов и переключение mute с сохранением нулевой громкости.
- Скачивание ночного видео, сверка SHA-256, изменение кадров в UI, остановка кадров на паузе и удаление фона. Отдельно проверен выбор собственного MP4 через штатный диалог.
- Минимальное окно с открытыми подробностями и выход из них через Escape. Скриншоты просмотрены на перекрытия и обрезку управления.

Скриншоты в README получены из реального окна. Видео MP4 длится 57,7 секунды, H.264, 1280×916, 24 fps, 989 528 байт; звуковой дорожки нет. В нём показаны оба вида каталога, избранное, наборы, отмена удаления, экспорт/импорт, Ctrl+Z и итоговый план. Записывается клиентская область с подписями; нативные файловые диалоги в видео не включены. Реальные установщики в этой проверке не запускались.

Воспроизведение (нужны Pillow и FFmpeg):

```powershell
python tools/capture_ui.py `
  --exe "C:\Build\SoftDownloader.exe" `
  --profile "C:\Temp\SoftDownloader-demo" `
  --output "C:\Temp\Screenshots" `
  --features --appearance --check-layout `
  --transfer "C:\Source\SoftDownloader\docs\examples\workstation.softdownloader.json" `
  --video "C:\Temp\SoftDownloader-demo.mp4"
```

Папки назначения/родитель профиля должны существовать. Прогону нужен разблокированный рабочий стол и свободный ввод. Громкость в тестовом профиле принудительно устанавливается в ноль, кнопки прослушивания не нажимаются. Имена установленных программ зависят от ПК; перед публикацией просмотрите свои кадры. Для записи достаточно API захвата конкретного окна, захват всего рабочего стола не требуется.

`tools/prepare_docs_media.py --source "C:\Temp\Screenshots" --video "C:\Temp\SoftDownloader-demo.mp4"` обновляет одобренные скриншоты и GIF в `docs/assets`. Экспортированные JSON и другие файлы тестового профиля не публикуются.

## Источники и Google Диск

Механизм публичных файлов Google Drive и встроенный канал дополнений поддерживаются. В `catalog/channel.json` пока `null`: реальный каталог дополнительного софта будет предоставлен позже. Проверены разбор файловых ссылок, привязка confirmation к исходному ID/хосту и локальные каталоги. Живое скачивание из Диска владельца ожидает его публичную коллекцию.

Проверки источников, выполненные в **0.2.0**, сохраняют историческую привязку к той версии:

- Подтверждены 80 точных WinGet ID и Shutdown PC Timer `9PB7GBMCR7N0` из `msstore`.
- Разрешены GitHub Releases Amnezia, FlClash, Happ, TgWsProxy, zapret, LiquidLauncher и Prism Cracked.
- Проверены версия/ссылка HTTP Debugger и Authenticode его MSI; отдельно скачан и проверен Authenticode 3uTools 9.10.006.
- ZIP zapret 1.10.3 и Prism Cracked 11.0.3 проверены по SHA-256 и CRC. У zapret есть верхняя папка (`strip_components: 1`), у обычной сборки Prism нет `portable.txt`.
- Страница 2IP StartGuard отвечала HTTP 503; карточка оформлена как ручная ссылка.

Эти проверки не являются гарантией доступности сторонних серверов на любую будущую дату.
