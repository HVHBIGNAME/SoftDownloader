# Проверки версии 0.4.0

Windows, 3 октября 2026 года. Основной каталог: **97 пакетов, 22 группы**.

## Автоматические проверки

| Проверка | Результат |
|---|---|
| `cargo fmt --all -- --check` | Пройдено |
| `cargo clippy --all-targets --locked -- -D warnings` | Без предупреждений |
| `cargo test --all-targets --locked` | **55 тестов**: 49 модульных, 1 lifecycle, 5 planning |
| `python -m unittest discover -s tools/tests -v` | **9 тестов** |
| JSON Schema Draft 2020-12 | Три встроенных каталога и отрицательные примеры проверены |
| `cargo build --release --bins --locked` | Оба EXE собраны со статическим CRT |

Интеграционный lifecycle создаёт изолированный ZIP и фиктивный portable EXE. Проверяются хеш, пропуск зависимой задачи после ошибки, сохранение истории, установка/замена и удаление только тестовых папок.

### Экспорт и импорт

- Unicode и атомарная перезапись экспортированного файла.
- Полный круг export → parse: сохранение неизвестного софта, исключение путей/команд, нормализация управляющих символов из реестра.
- Дедупликация ID; уже установленная программа с другой версией не выбирается повторно.
- Неизвестный ID не переназначается по совпавшему имени. Для записей без ID неоднозначное имя отмечается отдельно.
- Неподдерживаемая версия, лишние поля с рецептом установки, некорректный ID, повреждённый JSON и превышение 2 МБ отклоняются.
- План использует текущие версии/рецепты каталога, а не справочную версию из списка.

### Кэш и таймауты

- Повторная загрузка свежего кэша не вызывает сетевой загрузчик; явное обновление вызывает.
- Два профиля имеют независимые кэши. Изменение локального каталога инвалидирует сохранённые данные.
- Повреждённый кэш вызывает обновление с диагностикой. При отказе обновления возраст старого кэша не обнуляется.
- Предыдущий артефакт восстанавливается только для того же источника.
- Тесты с виртуальным временем проверяют реальные незавершающиеся запросы: общий бюджет сохраняет готовые ответы и конкретные ошибки; отдельный источник завершается по собственному таймауту. Интернет в этих тестах не нужен.

### Иконки

- Цвет, прозрачность и полупрозрачность восстанавливаются из отрисовки на двух фонах.
- Проверены чтение системной Windows-иконки, размеры 16–128 и выбор EXE вместо вспомогательных файлов.
- Разбор `DisplayIcon` поддерживает кавычки, пробелы, запятые в пути и суффикс индекса. Извлекается первый ресурс файла.
- Отсутствующая иконка не запрашивается снова каждый кадр; повтор разрешается после обновления инвентаризации.
- Иконка окна и ICO для EXE генерируются из одного рисунка. Ошибка компиляции Windows-ресурса останавливает сборку.

## Живой интерфейс

Приложение запущено с отдельным `--data-dir`. Сканирование обнаружило **184 программы**. Через штатный диалог сохранён JSON с 184 записями; проверены формат и состав полей. Затем импортирован учебный список: доступные пакеты попали в выбор каталога, установленное было отмечено отдельно. Открыт итоговый план установки и закрыто приложение с кодом 0.

Скриншоты в README получены из реального окна. Видео MP4 записывает клиентскую область окна с поясняющими подписями: группы, настройки, экспорт, импорт примера, выбранные программы и подтверждение. Нативные файловые диалоги находятся вне записываемой клиентской области. Запись заканчивается на плане; реальные установщики в этой проверке не запускались.

Воспроизведение (нужны Pillow и FFmpeg):

```powershell
python tools/capture_ui.py `
  --exe "C:\Build\SoftDownloader.exe" `
  --profile "C:\Temp\SoftDownloader-demo" `
  --output "C:\Temp\Screenshots" `
  --transfer "C:\Source\SoftDownloader\docs\examples\workstation.softdownloader.json" `
  --video "C:\Temp\SoftDownloader-demo.mp4"
```

Папки назначения/родитель профиля должны существовать. Имена установленных программ зависят от ПК; перед публикацией просмотрите свои кадры. Для записи достаточно API захвата конкретного окна, захват всего рабочего стола не требуется.

## Источники и Google Диск

Механизм публичных файлов Google Drive и встроенный канал дополнений поддерживаются. В `catalog/channel.json` пока `null`: реальный каталог дополнительного софта будет предоставлен позже. Проверены разбор файловых ссылок, привязка confirmation к исходному ID/хосту и локальные каталоги. Живое скачивание из Диска владельца ожидает его публичную коллекцию.

Проверки источников, выполненные в **0.2.0**, сохраняют историческую привязку к той версии:

- Подтверждены 80 точных WinGet ID и Shutdown PC Timer `9PB7GBMCR7N0` из `msstore`.
- Разрешены GitHub Releases Amnezia, FlClash, Happ, TgWsProxy, zapret, LiquidLauncher и Prism Cracked.
- Проверены версия/ссылка HTTP Debugger и Authenticode его MSI; отдельно скачан и проверен Authenticode 3uTools 9.10.006.
- ZIP zapret 1.10.3 и Prism Cracked 11.0.3 проверены по SHA-256 и CRC. У zapret есть верхняя папка (`strip_components: 1`), у обычной сборки Prism нет `portable.txt`.
- Страница 2IP StartGuard отвечала HTTP 503; карточка оформлена как ручная ссылка.

Эти проверки не являются гарантией доступности сторонних серверов на любую будущую дату.
