# Проверки версии 0.2.0

Проверено в Windows 2 октября 2026 года. Каталог: **97 пакетов, 22 группы**.

## Автоматические проверки

- `cargo fmt --all -- --check` — форматирование.
- `cargo clippy --all-targets --locked -- -D warnings` — без предупреждений.
- `cargo test --all-targets --locked` — **35 тестов Rust**: каталог, зависимости, пути, загрузка, SHA-256, Google Drive confirmation, источники, обнаружение ПО, Windows-аргументы и жизненный цикл пакетов.
- `python -m unittest discover -s tools/tests -v` — **9 тестов** подготовки и публикации каталога.
- JSON Schema Draft 2020-12 проверена на `builtin.json`, `extended.json`, `demo.json` и отрицательных примерах несовместимых managed/manual-рецептов.

Интеграционный тест создаёт изолированный ZIP и фиктивный portable EXE, проверяет пропуск зависимости после ошибки хеша, копирование portable без запуска, сохранение истории и удаление тестовых папок. Также проверяются различение веток JDK/Python, x64/x86 runtime, сохранение проверки хеша после сканирования и исключение устаревших записей истории.

## Реальные источники

Через `catalog-check --resolve` получены версии и SHA-256 релизов из репозиториев проектов:

- AmneziaVPN: `amnezia-vpn/amnezia-client`.
- FlClash: `chen08209/FlClash`.
- Happ: `Happ-proxy/happ-desktop`.
- TgWsProxy: `Flowseal/tg-ws-proxy`.
- zapret: `Flowseal/zapret-discord-youtube`.
- LiquidLauncher: `CCBlueX/LiquidLauncher`.
- Prism Cracked: `Diegiwg/PrismLauncher-Cracked`.

Версия и ссылка HTTP Debugger Pro прочитаны с официальной страницы; в первой версии отдельно проверен Authenticode скачанного MSI. В 0.2.0 дополнительно скачан **3uTools 9.10.006**, его Authenticode-проверка Windows прошла. EXE/MSI не запускались. Параметры FlClash сверены с Inno Setup-сценарием, тип установщика Happ подтверждён по заголовку EXE; Amnezia использует Qt Installer Framework.

ZIP zapret 1.10.3 и Prism Cracked 11.0.3 скачаны и сверены с опубликованными SHA-256. Проверены CRC и структура: zapret содержит верхнюю папку, для которой задан `strip_components: 1`; выбранный обычный ZIP Prism содержит `prismlauncher.exe` и не содержит `portable.txt`.

Подтверждены **80 точных ID источника `winget`** и **Shutdown PC Timer `9PB7GBMCR7N0` из `msstore`**. Проверка получала метаданные без установки программ.

Для AME Wizard найден официальный сайт `amelabs.net` и ссылка AME Beta ZIP. Hermes выбран из Nous Research с официальной инструкцией Windows. ESET Premium, AMD/NVIDIA и AME требуют выбора параметров в их мастерах. Страница 2IP StartGuard во время проверки возвращала HTTP 503; карточка содержит это состояние.

Живая проверка Google Drive ожидает рабочий публичный каталог владельца. Сейчас проверены разбор файловых ссылок, подтверждение больших файлов и локальный режим синхронизируемой папки.

## Интерфейс и сборка

Release EXE собран с оптимизацией и статическим CRT. Нативное окно запущено с отдельным профилем `--data-dir`: проверены загрузка метаданных, карточки, список установленного и поиск CLI. Скриншот в README получен из окна приложения.

Живое сканирование объединило реестр, Store, WinGet и локальные файлы. Проверены алиасы Happ с номером сборки, 2IP StartGuard с версией в имени, Store-пакеты Twinkle Tray и Shutdown PC Timer. Ошибки/таймауты одного источника выводятся отдельно; данные остальных источников сохраняются.

## Aislop

Результат сканирования: **91/100**, ошибок нет. Шесть предупреждений `hardcoded-url` оставлены как ложные срабатывания:

- фиксированный публичный endpoint скачивания Google Drive и его тест;
- тестовый домен `vendor.example` в двух проверках разбора HTML;
- построение `https://{host}/` для проверки разрешённых доменов в Rust и Python.

Это протокольные адреса, тестовые данные и валидаторы. Длинная функция карточки разделена; Python CLI отделён от модели каталога и файловых операций. Правила анализатора не отключались. `cargo audit` отдельно не выполнялся: утилита не установлена в локальном окружении.
