# Проверки первой версии

## Автоматические проверки

- `cargo fmt --all -- --check` — форматирование.
- `cargo clippy --all-targets --locked -- -D warnings` — без предупреждений.
- `cargo test --all-targets --locked` — 22 теста Rust: каталог, зависимости, пути, загрузка, SHA-256, Google Drive confirmation, официальные источники, Windows-аргументы и полный жизненный цикл тестового пакета.
- `python -m unittest discover -s tools/tests -v` — 6 тестов подготовки и публикации каталога.

Интеграционный тест создаёт изолированный ZIP-пакет, проверяет пропуск зависимого пакета после ошибки хеша, устанавливает независимый пакет, сохраняет историю и удаляет этот же пакет. В тестах не запускаются сторонние EXE/MSI и не удаляются программы пользователя.

## Реальные источники

Через `catalog-check --resolve` получены версии и SHA-256 релизов из официальных репозиториев:

- AmneziaVPN: `amnezia-vpn/amnezia-client`.
- FlClash: `chen08209/FlClash`.
- Happ: `Happ-proxy/happ-desktop`.

Версия и ссылка HTTP Debugger Pro прочитаны с официальной страницы. MSI был скачан отдельно командой `--download-only`; Authenticode-проверка Windows успешно завершилась. Установщик не запускался. Параметры FlClash сверены с Inno Setup-сценарием проекта, тип установщика Happ подтверждён по заголовку официального EXE; Amnezia использует Qt Installer Framework.

Живая проверка Google Drive ожидает рабочий публичный каталог владельца. Сейчас проверены разбор файловых ссылок, подтверждение больших файлов и локальный режим синхронизируемой папки.

## Интерфейс и сборка

Нативное окно было запущено в Windows; проверены загрузка официальных метаданных, обнаружение установленных программ и отображение карточек. Скриншот в README получен из запущенного приложения. Тестовый профиль отделён от основного через `--data-dir`.

## Aislop

Результат сканирования: **92/100**, ошибок нет. Пять нефункциональных предупреждений `hardcoded-url` оставлены как ложные срабатывания:

- фиксированный публичный endpoint скачивания Google Drive и его тест;
- тестовый домен `vendor.example`;
- построение `https://{host}/` для проверки разрешённых доменов в Rust и Python.

Это протокольные адреса, тестовые данные и валидаторы, а не URL окружений развёртывания. Правила и конфигурация анализатора не отключались. Проверка зависимостей через `cargo audit` отдельно не выполнялась: утилита не установлена в локальном окружении.
