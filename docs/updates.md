# Автоматическое обновление приложения

Начиная с **0.5.2**, SoftDownloader обновляет собственный EXE из [GitHub Releases](https://github.com/HVHBIGNAME/SoftDownloader/releases/latest). Автообновление включено по умолчанию, в том числе при загрузке настроек прежней версии.

## Как это работает

1. Примерно через 30 секунд после запуска и затем каждые 6 часов приложение проверяет последний релиз `HVHBIGNAME/SoftDownloader`.
2. Выбирается только более новая стабильная версия. Черновики, предварительные версии, одинаковые и более старые версии пропускаются. Версии сравниваются по SemVer: `0.5.10` новее `0.5.9`.
3. `SoftDownloader.exe` и `SoftDownloader.exe.sha256` скачиваются в фоне. Проверяются официальный адрес файлов, размер, SHA-256 и заголовок Windows x64 PE.
4. После завершения очереди, загрузок и диалогов появляется 15-секундный отсчёт. **Позже** откладывает применение до следующего запуска; **Продолжить обновление** возвращает отсчёт.
5. Настройки и выбранные программы сохраняются. Временная копия старого EXE запускается как вспомогательный процесс. Она подтверждает готовность, дожидается закрытия основного окна и заменяет EXE через Windows `ReplaceFileW` с резервной копией.
6. Новая версия запускается с прежними папкой данных и источником каталога. После создания окна она подтверждает запуск, и резервная копия удаляется.

Установка и перезапуск происходят автоматически — скачивать и заменять файл вручную для следующих выпусков не нужно. **Версию 0.5.2 нужно установить один раз вручную**, если сейчас используется 0.5.1 или более ранняя версия без этого механизма.

## Управление

Откройте **Настройки → Обновления**:

- включите или выключите автоматическое обновление;
- нажмите **Проверить сейчас**, чтобы не ждать следующего опроса;
- посмотрите ход скачивания, результат или сообщение об ошибке;
- откройте страницу релизов.

Для замены EXE нужна запись в папку, где он находится. Если файл лежит в защищённой или доступной только для чтения папке, приложение покажет ошибку; перенесите EXE в доступную пользователю папку. Права администратора автоматически не предоставляются.

## Ошибки и восстановление

- Ошибка сети или контрольной суммы оставляет установленный EXE на месте. Незавершённая загрузка удаляется.
- Перед заменой повторно проверяются скачанный файл и прежний EXE. Изменение файла другим процессом отменяет замену.
- Если новая версия завершается до открытия окна или не подтверждает запуск за 60 секунд, возвращается резервная копия и запускается прежняя версия.
- SHA-256 неудачного обновления сохраняется, чтобы избежать цикла обновление → сбой → откат. Повторное автоматическое скачивание этого файла заблокировано до исправленного выпуска.
- Другой открытый экземпляр приложения может мешать замене EXE; при ошибке закройте его и повторите проверку.

Результат хранится в `updates/result.json` внутри папки данных. Временные файлы завершённых обновлений очищаются при следующей проверке. Настройки, установленные программы и пользовательские видео не заменяются.

Обновление требует запущенного приложения. В отладочных сборках автоматическая замена отключена. Это обновление самого SoftDownloader; версии сторонних программ устанавливаются через обычную очередь каталога.

## Проверка разработчиком

```powershell
# Живой GitHub API; скачивание и проверка при наличии новой версии, без замены EXE:
cargo run --features catalog-tools --bin catalog-check --locked -- --app-update --data-dir "C:\Temp\sd-update-api"

# Полная замена и откат на временных копиях; нужен рабочий стол Windows:
python tools/check_self_update.py --exe dist/SoftDownloader.exe --temp-root "C:\Temp"
```

GUI-проверка не изменяет исходный EXE. Она создаёт временные копии с беззвучными профилями и выключенными сетевыми автообновлениями, проверяет ожидание выхода родителя, замену байтов, нативный перезапуск, сохранение профиля и откат при неподтверждённой версии.
