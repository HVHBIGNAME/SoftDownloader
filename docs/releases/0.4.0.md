# SoftDownloader 0.4.0

## Один EXE

Скачайте **`SoftDownloader.exe`** и запустите. Каталог, шрифты и иконки встроены; рядом не нужны файлы данных или DLL. Приложение использует штатные библиотеки Windows и статический CRT.

Обычная сборка также создаёт один бинарный файл. CLI проверки каталога вынесен за feature `catalog-tools`. Размер релизной сборки уменьшен через full LTO, `opt-level=z`, удаление отладочных символов и неиспользуемых возможностей парсера HTML.

Локальная сборка уменьшилась с 9,67 до **6,72 МиБ** (−30,5%). Проверены SHA-256, отсутствие внешнего runtime и запуск EXE из отдельной папки со встроенными каталогом и иконками.

## Списки программ

- **Установлено → Экспорт списка** сохраняет весь обнаруженный софт в JSON, включая записи вне каталога.
- **Импорт списка / Ctrl+O** открывает предпросмотр с поиском и выбором. Уже установленное пропускается; неизвестные и недоступные записи остаются справочными.
- **Добавить к выбору** переносит отмеченные программы в каталог. Установка начинается после подтверждения плана, зависимости добавляются автоматически.
- Дубликаты ID объединяются. Файл переносит названия, версии, издателей и ID; рецепты установки берутся из текущего каталога.

## Интерфейс

- Короткие переходы страниц, плавная подсветка и настройка уменьшения анимации.
- Нижняя панель появляется при выборе или работающей очереди. Уведомления не сдвигают страницы.
- Список установленного виртуализирован; действия программы собраны в меню.
- Исправлены повторное чтение отсутствующих иконок, прозрачность и освобождение GDI-ресурсов. Окно и EXE используют один логотип.

## Источники

- Google Диск оформлен как встроенный канал будущего дополнительного софта. Публичная коллекция пока не задана; основной каталог работает самостоятельно.
- Кэш учитывает профиль, версию приложения и изменения локального каталога. Явное обновление обходит кэш.
- Таймаут не теряет уже полученные ответы и не подменяет конкретную ошибку общим сообщением. Сохранённые данные отмечаются явно.
