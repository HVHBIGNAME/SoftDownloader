# SoftDownloader 0.5.2 — автообновление, расширенный каталог и видеофон

## Полностью автоматическое обновление

SoftDownloader проверяет GitHub Releases при запуске и каждые 6 часов. Новая стабильная версия скачивается в фоне, проверяется по SHA-256 и автоматически заменяет EXE с перезапуском. Очередь установки/удаления не прерывается, настройки и выбор сохраняются. Если новая версия не запускается, выполняется откат.

Автообновление включено по умолчанию. В **Настройки → Обновления** доступны выключатель, проверка вручную и статус; перед перезапуском можно нажать **Позже**. Для замены EXE нужна запись в его папку. Для перехода с 0.5.1 и более ранних версий скачайте 0.5.2 вручную один раз.

## Каталог и интерфейс

Каталог вырос с **97 до 224 пакетов**, число групп — с **22 до 26**. Добавлено 96 программ WinGet и 31 расширение VS Code.

- **Менеджеры модов:** r2modman, Vortex и Mod Organizer 2; ATLauncher и CurseForge доступны в Minecraft.
- **Игры:** Epic, GOG, Heroic, Playnite, GeForce NOW, Moonlight, Parsec и Ubisoft Connect.
- **Разработка:** JetBrains Toolbox, Android Studio, Neovim, Vim, Unity Hub, Godot, Bun, Deno, Zig и Julia.
- **Командная строка и базы данных:** PowerShell 7, GitHub CLI, CMake, Ninja, LLVM, ripgrep, fd, bat, fzf, lazygit, Yazi, FFmpeg, DBeaver и HeidiSQL.
- **Расширения VS Code:** Python, Pylance, Rust, Go, C/C++, C#, Jupyter, GitLens, Prettier, ESLint, Ruff, Remote SSH, WSL, Continue, Roo Code, Copilot и другие.
- **Повседневные задачи:** Joplin, Anki, LibreOffice, ONLYOFFICE, calibre, HWiNFO, CPU-Z, GPU-Z, WizTree, HandBrake, Kdenlive, REAPER, Figma, Ollama и LM Studio.

Зависимости добавляются в план автоматически: редактор устанавливается перед расширениями, общие зависимости не дублируются, установленное пропускается. Обнаружение использует WinGet, реестр, известные пути, PATH и метаданные расширений. Стабильные ID существующих пакетов сохранены.

**Видеофон** теперь покрывает всё окно, включая боковую панель, карточки и область выбора. Он не смещается при прокрутке и открытии подробностей. Текст сохраняет контраст, диалоги подтверждения остаются непрозрачными, а предпросмотр исходного видео можно свернуть. При смене файла прежний кадр очищается.

В карточке **ESET HOME Security Premium** добавлена прямая официальная ссылка на Live Installer. После скачивания откройте мастер и войдите в ESET HOME или укажите лицензию.

**Проверки:** 84 Rust-теста, 10 Python-тестов, форматирование и Clippy; подтверждены новые WinGet ID и страницы Marketplace. На временных копиях проверены полная замена EXE, автоматический перезапуск и откат при ошибке запуска. Проверены самостоятельный EXE и видеофон на всех страницах, при прокрутке, открытии подробностей и изменении размера окна. Подробности — в [отчёте](https://github.com/HVHBIGNAME/SoftDownloader/blob/v0.5.2/docs/verification.md).

Скачайте **SoftDownloader.exe** для Windows x64 из файлов релиза и замените прежний файл. Настройки хранятся отдельно. Для проверки загрузки приложен `SoftDownloader.exe.sha256`. Игровые сборки, интерпретаторы проектов и языковые модели выбираются в соответствующих приложениях.
