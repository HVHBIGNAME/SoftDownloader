# SoftDownloader 0.5.0

Настраиваемый интерфейс, избранное, мягкие звуки и настоящие видеофоны. Приложение по-прежнему поставляется одним `SoftDownloader.exe` для Windows 10/11 x64, размер — около 7 МиБ.

## Что нового

- **Ровный каталог.** Компактный список по умолчанию, карточки по выбору, Segoe UI и единые отступы. Выбор и «Установлено» находятся в одном фиксированном слоте. Меню «Вид» выровнено, сообщения источников не сдвигают управление.
- **Избранное и свои наборы.** Звёздочки, быстрые фильтры, сортировка по имени, просмотр всего выбора и сохранение коллекций. Очистка отменяется через «Вернуть» или Ctrl+Z. Экспорт набора не сужается поиском.
- **Четыре темы и свой акцент.** Тёмная, светлая, серая и ночная. Контраст текста сохраняется при смене темы, а настройки применяются сразу.
- **Комфортный звуковой отклик.** Три набора коротких приглушённых касаний вместо резких тональных сигналов. Плавные края, ослабленные высокие частоты, ограничение пиков, громкость по умолчанию 18%, отключение и отдельные кнопки прослушивания.
- **Сезонные эффекты.** Падающий снег и тыква на Хэллоуин: по календарю, вручную либо полностью выключены.
- **Настоящее видео на фоне.** Свой MP4 или два скачиваемых ролика Mixkit. Проверка SHA-256, предпросмотр, приглушение и пауза. Воспроизведение средствами Windows, по кругу, без звука; ролики не включены в EXE.

## Обновление

Замените прежний EXE новым. Настройки и избранное хранятся в папке данных приложения. Формат списков программ остаётся `softdownloader.program-list`, версия 1: экспорт из 0.4.0 поддерживается.

Основной каталог содержит 97 пакетов в 22 группах. Встроенный Google Диск предназначен для будущих дополнений; публичная дополнительная коллекция пока не задана.

## Проверено

- 73 Rust-теста, 9 Python-тестов, форматирование, Clippy и схемы каталогов.
- Живой интерфейс: оба вида каталога, избранное, сохранение наборов, импорт, Ctrl+Z, отмена удаления и минимальный размер окна.
- Темы и акценты, сезонные эффекты, звуковые настройки с нулевой громкостью в автоматическом прогоне.
- Скачивание настоящего видео, хеш, смена кадров, пауза, удаление фона; нативный декодер с Unicode-путями и точной перемоткой.
- Самостоятельный x64 EXE, иконка и только системные DLL; запуск из отдельной папки и нормальное закрытие.

Скачайте **SoftDownloader.exe**. `.sha256` нужен только для проверки файла. **SoftDownloader-0.5.0-demo.mp4** — 58-секундная запись реального интерфейса без звука; она заканчивается на плане установки.
