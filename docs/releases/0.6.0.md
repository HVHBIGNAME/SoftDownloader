# SoftDownloader 0.6.0 — удобнее, мягче, больше полезного софта

## Обновлённое оформление

- Округлые карточки и диалоги, единый радиус кнопок и полей, фильтры-капсулы.
- Выбранные программы выделяются рамкой и фоном; поиск подсвечивается при фокусе.
- Счётчики в боковой панели, отдельная иконка наборов и аккуратная панель установки.
- Список и карточки проверены в светлой и тёмной теме; основные действия помещаются в окне 1024×700.

## Ещё 16 полезных программ

- **Каждый день:** LocalSend, KDE Connect, QuickLook, Ditto, CopyQ и Flow Launcher.
- **Документы и медиа:** PDF24 Creator, NAPS2, File Converter, ScreenToGif и ImageGlass.
- **Система и файлы:** Auto Dark Mode, Bulk Crap Uninstaller, UniGetUI, Double Commander и Duplicati.

Для каждой программы проверены актуальный ID и рецепт WinGet. Используются стабильные пакеты; для Auto Dark Mode и UniGetUI также учитываются прежние ID при обнаружении установленного ПО.

## Установить одной кнопкой

- **Установить** сразу запускает выбранный софт. Зависимости добавляются автоматически, уже установленное пропускается.
- Рядом с кнопкой — **Тихая установка / С мастером**. Для отдельных программ можно сохранить свои режимы.
- Быстрый запуск программы доступен прямо из строки списка, карточки и подробностей.
- **План** доступен отдельно. Постоянное подтверждение включается в **Настройки → Установка**.

## Готовые и свои наборы

Восемь подборок: **Базовый ПК**, **Работа и учёба**, **Удобная Windows**, **Документы и сканы**, **Разработка**, **Веб-разработка**, **Игры и общение**, **Творчество**.

Сохраняйте выбор или избранное под своим именем, обновляйте состав и экспортируйте JSON для другого ПК. Удалённый набор можно вернуть. Выбор программ сохраняется при обычном закрытии приложения.

## Очередь и установщики

- Общий прогресс, режим каждой задачи, пауза после текущей и продолжение.
- Повтор незавершённых задач, включая повтор с мастером, и кнопка открытия логов.
- Недоступная программа не блокирует остальные; причина показывается отдельно.
- **ESET Premium** теперь скачивается через очередь, проверяется по подписи Windows и открывает официальный Live Installer. Активация — в мастере ESET.
- В предпросмотре импортированного списка можно сразу нажать **Установить сейчас**.

Каталог содержит **240 пакетов и 26 групп**. Автообновление из GitHub Releases сохраняется: версия 0.5.2 может обновиться до 0.6.0 автоматически.

**Проверки:** 94 Rust-теста, 11 Python-тестов, Clippy и форматирование. Проверка интерфейса в egui запускает только изолированный portable-пакет; подтверждены установка одним нажатием, блокировка запуска при обязательном плане, переключение режима и сохранение/удаление/восстановление наборов при минимальном размере окна.

Скачайте **SoftDownloader.exe** из файлов релиза. Тихий режим не отменяет обязательные мастера, запросы UAC и вход в аккаунты сторонних программ.
