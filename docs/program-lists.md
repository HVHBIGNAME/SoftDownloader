# Перенос списка программ

Список SoftDownloader — JSON-файл для повторной установки программ из актуального каталога. Он содержит названия, версии, издателей и стабильные ID пакетов.

## Экспорт

1. Откройте **Установлено** и дождитесь завершения сканирования.
2. Нажмите **Экспорт списка**, выберите имя и папку файла.
3. Сохраните файл рядом с другими данными для переноса на новый ПК.

Экспортирует **все обнаруженные программы**, независимо от поискового фильтра и галочек удаления. В файл попадают также программы вне каталога: их названия пригодятся для ручного восстановления. Пути к файлам, команды удаления, настройки программ и пользовательские документы в этот формат не входят.

## Импорт и выбор

1. Нажмите **Импорт списка** в каталоге/установленном или **Ctrl+O**.
2. Выберите JSON-файл. В предпросмотре есть поиск и кнопки **Выбрать доступные / Снять выбор**.
3. Отметьте нужное и нажмите **Добавить к выбору**.
4. Каталог покажет выбранные записи из списка. **Весь каталог** возвращает общую коллекцию, сохраняя галочки.
5. Нажмите **Установить выбранное** и подтвердите план с зависимостями.

| Состояние | Поведение |
|---|---|
| Можно установить | Отсутствующий пакет доступен в текущем каталоге; отмечен по умолчанию. |
| Уже установлено | На этом ПК найден пакет с тем же ID. Импорт не ставит его повторно, даже если сохранённая версия отличается. |
| Пока недоступно | Пакет известен, но требует ручной установки или не имеет доступного установщика. |
| Нет в каталоге | Запись остаётся справочной. Дополнительный пакет станет доступен после подключения его каталога. |
| Неоднозначное имя | Для записи без ID найдено несколько вариантов. Выберите правильную программу в каталоге вручную. |

Импорт добавляет выбор к уже отмеченным программам. Повторяющиеся ID объединяются. Сам импорт не запускает скачивание или установщик.

## Формат 1

```json
{
  "format": "softdownloader.program-list",
  "schema_version": 1,
  "created_at": 1790985600,
  "app_version": "0.4.0",
  "programs": [
    {
      "package_ids": ["vscode"],
      "name": "Visual Studio Code",
      "version": "1.100.0",
      "publisher": "Microsoft"
    },
    {
      "package_ids": [],
      "name": "Моя дополнительная утилита",
      "version": "1.0",
      "publisher": "Моя команда"
    }
  ]
}
```

`created_at` — Unix timestamp в секундах. `version` служит справкой: рецепты, URL и параметры установки берутся исключительно из текущего каталога. Строки из реестра при экспорте приводятся к одной строке, удаляются управляющие символы.

Сопоставление идёт по ID SoftDownloader. У записи с неизвестным ID имя не используется для подстановки другой программы. У записи без ID допускается только однозначное совпадение имени/алиаса из каталога.

Лимиты: **2 МБ**, **5000 записей**, до 64 ID у записи. Неизвестные поля, неподдерживаемая версия формата, некорректные ID и управляющие символы отклоняются с сообщением. UTF-8 BOM поддерживается. Запись выполняется через временный файл с атомарной заменой.

Готовый учебный список: [`examples/workstation.softdownloader.json`](examples/workstation.softdownloader.json). Это пример коллекции, а не экспорт с конкретного компьютера.
