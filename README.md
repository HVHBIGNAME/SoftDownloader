## Начать работу

1. Скачайте **[SoftDownloader.exe](https://github.com/HVHBIGNAME/SoftDownloader/releases/latest/download/SoftDownloader.exe)** и запустите его.
2. Дождитесь проверки установленного ПО. Отметьте программы в каталоге или откройте **Наборы программ**.
3. Выберите **Тихая установка** или **С мастером** и нажмите **Установить**. Очередь запускается сразу; результат каждой программы виден отдельно.

Кнопка **План** показывает зависимости до запуска. Обязательное подтверждение можно включить в **Настройки → Установка**.

Для пакетов WinGet нужен [Установщик приложений Microsoft](https://apps.microsoft.com/detail/9nblggh4nns1). EXE/MSI при необходимости откроют штатный мастер или запрос UAC.

Само приложение поставляется одним файлом, работает с системными библиотеками Windows и хранит настройки/кэш в AppData. Установка Rust, Python или отдельного runtime для его запуска не требуется. Файл `.sha256` в релизе — необязательная проверка скачивания; видео и документация доступны отдельно.

**Автообновление с 0.5.2:** приложение само проверяет GitHub Releases, скачивает новую стабильную версию, проверяет SHA-256, заменяет EXE и перезапускается после завершения текущих операций. Настройки и выбор сохраняются; при неудачном запуске возвращается прежний EXE. Управление — **Настройки → Обновления**. Для перехода с 0.5.1 и старше скачайте новый файл один раз. **[Как работает обновление](docs/updates.md)**.

## Установка и наборы

- **Одна кнопка:** запуск всего выбора, готового набора или отдельной программы через **↓** в строке, кнопку в карточке или подробностях.
- **Два режима:** тихие параметры либо штатный мастер. У отдельной программы можно задать исключение; настройки уже запущенной очереди не меняются.
- **Десять готовых наборов:** базовый ПК, работа и учёба, удобная Windows, документы и сканы, учёба и исследования, диагностика Windows, разработка, веб-разработка, игры и общение, творчество. Состав раскрывается перед установкой.
- **Мои наборы:** сохраните выбор или избранное под своим именем, обновите состав, экспортируйте JSON. Удаление набора можно отменить кнопкой **Вернуть**.
- **Понятная очередь:** общий прогресс, режим каждой задачи, пауза после текущей, отмена следующих, повтор незавершённых — в том числе с мастером — и открытие логов.
- **Независимые задачи продолжаются:** недоступная программа не блокирует весь набор; её причина видна отдельно. Неустановленная зависимость блокирует только зависимые программы.

## Каталог под себя

- **Список или карточки** — переключаются в меню **Вид**. Выбор, статус установки и избранное занимают одинаковые фиксированные места.
- **Мягкое оформление** — единые скругления, фильтры-капсулы, счётчики в навигации и отдельная панель установки. Выбранные карточки выделяются рамкой и фоном, поиск — рамкой при фокусе.
- **Избранное** — звёздочка рядом с программой сохраняет её в вашей коллекции, включая уже установленное ПО.
- **Все / Доступные / Выбрано** — быстрые фильтры. Поиск **Ctrl+K / Ctrl+F**, группы и сортировка по имени помогают сузить список.
- **Выбрано** показывает весь выбор. Его можно сохранить как набор или JSON; случайную очистку отменяют **Вернуть** или **Ctrl+Z**. Выбор сохраняется при обычном закрытии приложения.

## Первый запуск и обновления

При первом запуске открывается короткий гайд из пяти шагов. **Начать работу** или **Пропустить** сохраняет прохождение в локальном `settings.json`; повторно он сам не открывается. Кнопка **Помощь** позволяет вернуться к нему.

После смены версии показывается небольшая таблица **Что нового**. Она появляется один раз для каждой версии после подтверждения **Понятно**. Открыть её снова можно в **Настройки → Обновления**.

## Перенос списка программ

**На текущем ПК:** `Установлено → Экспорт списка` → сохраните JSON-файл.

**На новом ПК:** `Импорт списка` или **Ctrl+O** → выберите файл → отметьте нужное → **Установить сейчас**. Кнопка **Добавить к выбору** позволяет сначала дополнить список в каталоге.

- В экспорт попадает полный обнаруженный список, включая программы вне каталога.
- Доступные отсутствующие программы отмечаются в предпросмотре; выбор можно изменить.
- Уже установленные пропускаются. Неизвестные и недоступные записи видны с пояснением.
- Используются рецепты текущего каталога. Сохранённые версии служат справкой; зависимости добавляются автоматически.
- **Экспорт JSON…** в избранном или просмотре выбора экспортирует всю вашу коллекцию, независимо от поискового фильтра.

## Сборка и проверки

Нужны Rust **1.88+**, MSVC toolchain и Visual Studio Build Tools с компонентом Desktop development with C++.

```powershell
cargo run --release

cargo fmt --all -- --check
cargo clippy --all-targets --all-features --locked -- -D warnings
cargo test --all-targets --all-features --locked
python -m unittest discover -s tools/tests -v

cargo build --release --locked
powershell -ExecutionPolicy Bypass -File tools/package.ps1
python tools/verify_standalone.py --file dist/SoftDownloader.exe
```

Отдельный профиль: `SoftDownloader.exe --data-dir "C:\Temp\SoftDownloader-test"`.
Локальный каталог дополнений: `SoftDownloader.exe --catalog "G:\Мой диск\SoftDownloader\catalog.json"`.

Обычный `cargo build --release` собирает только приложение: `target/release/softdownloader.exe`. Скрипт выпуска копирует его в `dist/SoftDownloader.exe` и записывает контрольную сумму.

Служебный CLI собирается отдельно: `cargo run --features catalog-tools --bin catalog-check -- --resolve`. Флаги `--check-winget` и `--inventory` проверяют ID и обнаружение программ, `--video clip.mp4 --frame frame.png` — нативное декодирование и перемотку видео. CLI предназначен разработчику и в пользовательский релиз не входит. Интеграционные тесты установки/удаления используют изолированные фиктивные пакеты. **[Результаты проверок](docs/verification.md)**.

Снимки гайда, таблицы изменений, погоды и сезонов 0.7.0 воспроизводятся через [`tools/check_experience_ui.py`](tools/check_experience_ui.py). Прежние walkthrough и видео — через [`tools/capture_ui.py`](tools/capture_ui.py), медиа README — через [`tools/prepare_docs_media.py`](tools/prepare_docs_media.py), иконка — через [`tools/make_branding.py`](tools/make_branding.py). Этим инструментам нужен Pillow; видео также использует FFmpeg. GUI-прогоны принудительно устанавливают нулевую громкость в отдельном тестовом профиле. Исходные звуки и графика подготавливаются [`tools/prepare_ui_assets.py`](tools/prepare_ui_assets.py).

### Основные модули

```text
src/program_list.rs    экспорт, валидация и сопоставление списков
src/program_sets.rs    готовые и именованные наборы программ
src/installation.rs    общие и индивидуальные режимы установки
src/catalog_filter.rs  поиск, избранное и просмотр выбора
src/preferences.rs     темы, сезоны, звуки и видеофон
src/backgrounds.rs     каталог и проверка скачиваемых видео
src/weather.rs         поиск городов, прогноз и локальный кэш погоды
src/video/             нативный Windows Media Foundation decoder
src/catalog_cache.rs   кэш, обновление и восстановление метаданных
src/config.rs          встроенный канал дополнений
src/updater.rs         проверка релизов и загрузка обновления приложения
src/updater/           замена EXE, проверка запуска и откат
src/catalog.rs         каталог, категории и зависимости
src/discovery.rs       GitHub Releases и официальные сайты
src/inventory.rs       обнаружение и сопоставление программ
src/engine.rs          фоновые задачи и последовательная очередь
src/ui/                интерфейс и фоновые иконки
src/system/            WinGet, Store, VS Code и Windows API
src/installer/         установщики, подписи, ZIP и portable
src/uninstall/         реестр и способы удаления
tools/catalog.py      подготовка дополнительных пакетов
```

Настройки, история, кэш и журналы хранятся локально; папка открывается из настроек. Исходный код — [MIT](LICENSE); материалы оформления — по [указанным лицензиям](assets/CREDITS.md). Сторонние программы распространяются на условиях своих разработчиков.
